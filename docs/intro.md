# Content & Assessment Workflow Options

ThinkTurf runs in-school chess instruction across 50+ Bengaluru schools.
Onboarding (Tutor / School / Student-Parent) is settled and required for
MVP. What's still open is **how content gets to students and how progress
gets captured** — three options are on the table.

| Option | One-line summary |
|---|---|
| **A — Platform Tutorial + Assessment** | Full digital curriculum (in-session + homework) plus an independent, platform-scored chess skill assessment. |
| **B — Tutor-Based Feedback** | Tutor delivers from a lesson plan; attendance + session note + rating is the entire progress record. |
| **C — Hybrid** | Full digital curriculum delivery, but the tutor stays the single source of truth for progress — no separate scoring engine. |

All three share two fixed blocks that don't change with this decision:

- **Onboarding** — Tutor / School / Student-Parent lifecycle, parent consent gate.
- **Cognitive Skill Snapshot** — the existing six-domain, age-banded assessment, run on its own six-month cycle. This is independent of chess content or delivery model.

See **Workflow Diagrams** in the sidebar for the full flow of each option,
and **Comparison** for pros, cons, and relative build effort.
